# OpenScenaio
This document used to record the OpenScnario(OSC) file made by ITRI based on map `hct_6.xodr`.

## Test code

```bash
rosrun esmini esmini --osc /resources/xosc/itri/hct_xx.xosc --window 0 0 1200 800
```


## The following is used to describe each OpenScenarios file

hct_00: test code\
hct_01: test code\
hct_02: special case of SC31\
hct_03: test code\
hct_04: special case of SC34\
hct_05: based on SC31\
hct_06: based on SC34

SCxx based on [CETRAN](https://cetran.sg/wp-content/uploads/2020/01/REP200121_Scenario_Categories_v1.7.pdf)
