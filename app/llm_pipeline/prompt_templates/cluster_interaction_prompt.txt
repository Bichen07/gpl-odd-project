<Traffic Interaction Types (Reference)>
When describing interactions, you may reference these standard types:

- **Distance keeping (DK):** Ego adjusts speed to maintain safe following distance behind lead vehicle
- **Yielding at intersection for crossing path conflict (YCP):** Ego slows/stops to let conflicting agent pass whose path crosses ego's intended path
- **Yielding at intersection for merging path conflict (YMP):** Ego yields to agent merging into same target lane from different entry
- **Proceeding after conflict resolved (P):** Ego accelerates through intersection after conflicting agent clears or gap opens
- **Proactive deceleration (PD):** Ego slows down preventatively before conflict materializes
- **Reactive braking (RB):** Ego brakes hard in response to imminent collision threat
- **Hesitation (H):** Ego decelerates and re-accelerates, showing uncertainty about right-of-way

You may also define new interaction types if the behavior doesn't fit these categories.
</Traffic Interaction Types (Reference)>
